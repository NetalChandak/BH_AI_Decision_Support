# Calculation logic

## Public transport

The analysis does not claim a statistically fitted CAGR. Instead, it uses a bounded calibration approach:

1. Start from the source baseline (~9% Riyadh PT).
2. Establish the long-term NoRA ambition (40%+ PT).
3. Introduce NoRA-specific structural uplift factors: greenfield development, higher density, TOD, integrated transit/accessibility planning.
4. Discount the long-term ambition for 2030 delivery/adoption uncertainty.
5. Produce a working range of 25–30%.
6. Stress the delivery/adoption assumptions to produce ~19–35% sensitivity.

## Internal sustainable modes

1. Start from the source KPI of 50%+ and the longer-term 70–80% benchmark/targeting range.
2. Recognise that 2030 is transitional.
3. Apply lower adoption assumptions for early-stage delivery.
4. Produce ~45% working estimate.
5. Stress the assumptions to 35–55%.

## Internalisation

1. Start from the 70%+ NoRA KPI.
2. Recognise that internalisation depends on mixed-use development, density, job/resident balance and phasing.
3. Use ~55–60% as a working 2030 range.
4. Stress to ~50–65%.

## Mathematical note

The ranges are **calibration outputs**, not a claim that each input has a measured elasticity. A future detailed travel-demand model should replace these assumptions with calibrated trip generation, distribution and mode-choice parameters.
