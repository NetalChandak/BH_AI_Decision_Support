# Source handling and confidentiality

The original NoRA PPTX and RUA PDF were available during analysis but are not duplicated in this GitHub-ready package by default.

Reasons:

1. The documents may contain client/confidential material.
2. The RUA PDF is approximately 161 MB and is therefore unsuitable for a normal GitHub repository file.
3. The NoRA PPTX is approximately 48 MB and may also be subject to project restrictions.
4. The evidence package only needs the relevant source references and extracted facts for auditability.

If the repository is private and the user has permission to distribute the documents, they can be added separately under `02_Source_Evidence/original_sources/`.

Recommended practice for a public repository: keep source names, page/slide references and short extracted evidence, but do not publish confidential source files.
