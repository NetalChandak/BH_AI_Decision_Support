# P002 — Independent NoRA estimate

## User prompt

> Can you compute these numbers by yourself? Consider historical data, future estimates, and various growth factors. Feel free to come up with various growth factors scenarios. I have attached the input file that I received. Let me know if you need any further information. Then, we can compare with what the pdf is saying is similar or not?

## Task

Develop an independent NoRA 2030 estimate rather than reusing RUA/CMP targets as inputs.

## Model response used

The working analysis identified:

- Riyadh current PT context: ~9%.
- NoRA long-term PT ambition: 40%+.
- NoRA sustainable internal-mode KPI: 50%+.
- NoRA internalisation KPI: 70%+.
- NoRA population context: ~3.0M ±7.5%.
- NoRA greenfield/TOD/accessibility-led planning as structural factors.
- Need for scenario ranges because detailed NoRA demand/capacity modelling is not yet available in the supplied source pack.

The resulting working estimate was subsequently refined to the evidence-package values documented in `05_2030_Model/`.
