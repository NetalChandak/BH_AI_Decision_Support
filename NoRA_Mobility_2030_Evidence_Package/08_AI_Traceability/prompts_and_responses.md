# Project #1 — Selected prompts and responses

## P001 — Source vs calculation

**Prompt:** Did you get these numbers from pdf file attached or did you compute it from your data? If you computed yourself what parameters did you use?

**Response used:** The RUA/CMP 60%, 40%, 54%, 30% and 16% values were directly stated in the PDF. The 100% internal sustainable figure was calculated as 54% + 30% + 16%. These are planning targets, not automatically 2030 observed forecasts.

## P002 — Independent NoRA estimate

**Prompt:** Can you compute these numbers by yourself? Consider historical data, future estimates, and various growth factors. Feel free to come up with various growth factors scenarios. I have attached the input file that I received. Let me know if you need any further information. Then, we can compare with what the pdf is saying is similar or not?

**Response used:** Develop an independent scenario-based NoRA 2030 estimate using the Riyadh baseline, NoRA targets, greenfield/TOD characteristics, transit supply, parking/TDM, behavioural adoption, phasing and population context. Do not use RUA/CMP targets as NoRA model inputs.

## P003 — Reason column

**Prompt:** In the independent 2030 estimate, can you add a reason column on what basis you came up with these numbers?

**Response used:** Add a source/assumption rationale to each metric and explicitly identify values that cannot be independently decomposed without unsupported assumptions.

## P004 — Evidence package

**Prompt:** Do you remember this project? Where we came up with the above numbers. Project #1 — NoRA mobility targets. I want to create an evidence package. Do you know what all should I add over there and should I upload the prompts and responses in the github or what to do?

**Response used:** Structure the evidence package around source evidence, baseline, methodology, assumptions, model, sensitivity, comparison, AI traceability, QA and limitations. Keep prompts/responses as an audit trail rather than the main evidence.

## P005 — Package creation

**Prompt:** Can you create the whole folder structure, files and everything maybe in zip format or whatever works? I'll just download the whole package and upload to github the whole package in a single commit. Make sure to include the responses whenever needed.

**Response:** This repository is the resulting GitHub-ready package. Original confidential/large source files are referenced but not copied by default.
