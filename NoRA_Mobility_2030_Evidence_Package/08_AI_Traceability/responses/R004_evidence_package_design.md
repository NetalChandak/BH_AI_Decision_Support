# R004 — Evidence package design

The recommended evidence package separates:

1. source evidence;
2. historical baseline;
3. assumptions;
4. methodology;
5. 2030 model;
6. sensitivity analysis;
7. comparison with benchmark targets;
8. AI prompt/response traceability;
9. QA and limitations;
10. final decision-facing output.

The recommendation was to keep prompts/responses as an audit trail rather than making them the main evidence. The main evidence should remain the source-to-assumption-to-calculation chain.
