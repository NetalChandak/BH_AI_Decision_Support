# AI traceability

This folder contains the **material prompts and curated responses** needed to understand how Project #1 evolved.

## Why curated rather than a full chat export?

A raw transcript is difficult to audit and contains conversational material that is not part of the analytical method. The repository instead records the prompts that materially changed the evidence, assumptions, methodology or outputs.

## Audit pattern

For each material prompt:

**Prompt → Inputs → AI response → analyst challenge/review → final model decision**

## Recommended practice

If this project is later rerun with a different AI model, record:

- model name/version;
- date;
- prompt ID;
- input source versions;
- output;
- human review/change;
- final adopted value.

The AI is an analytical support tool. Source evidence and approved project inputs remain authoritative.
