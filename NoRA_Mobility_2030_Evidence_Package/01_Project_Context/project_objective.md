# Project objective

## Business problem

Future-facing business and urban-development decisions can be influenced heavily by human judgement and point assumptions. The objective of this case is to demonstrate an AI-assisted workflow that converts scattered project evidence and external benchmarks into a transparent, scenario-based decision input.

## Project question

For NoRA, what could 2030 public transport mode share, internal sustainable-mode share and internalisation plausibly look like, and how does that independent estimate compare with stated planning ambitions?

## Decision metrics

1. Public transport mode share
2. Internal trips by sustainable modes — public transport, walking and micromobility
3. Trips internalised within NoRA
4. Population / development scale as a demand driver

## Analytical principle

The project separates:

- **Source facts** — directly stated in project or external sources
- **Planning targets** — aspirations/KPIs stated by the project
- **Model assumptions** — values introduced for forecasting
- **Model outputs** — calculated working estimates
- **Sensitivity ranges** — outputs under alternative assumptions

No modelled value should be presented as a confirmed project commitment.
