# Methodology
1. Extract source targets.
2. Identify drivers: PT capacity, pilgrimage/visitor demand, low-car design, seasonal operations, demand management, walking, PRT, micromobility.
3. Define scenarios:
   - Conservative = source case / minimal uplift.
   - Base = modest improvement.
   - Accelerated = stronger adoption.
4. Calculate external car as `100% - PT`.
5. Constrain normal internal shares to 100%.
6. Label all scenario adjustments as assumptions.

No empirical CAGR is claimed because a sufficient RUA historical time series is not available in the source.
