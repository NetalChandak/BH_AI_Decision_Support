# Limitations
1. Source values are planning targets, not a complete observed time series.
2. Scenario uplifts are not statistically estimated growth rates.
3. No network assignment/capacity model.
4. Pilgrimage demand is seasonal.
5. 2030 is not automatically full build-out.
6. PRT and micromobility depend on delivered infrastructure/operations.
7. Scenario ranges are not probabilities.
8. Validate against formal travel-demand model when available.
